## Story

**As a** usuario do sistema,
**I want** ver um mapa visual dos assentos ao criar uma reserva,
**so that** eu saiba quais assentos estao disponiveis e escolha facilmente.

## Acceptance Criteria

1. Ao selecionar um voo no formulario de reserva, exibir grid visual de assentos
2. Assentos ocupados em vermelho (nao clicaveis), disponiveis em verde (clicaveis)
3. Ao clicar num assento disponivel, preencher automaticamente o campo `numero_assento`
4. Grid gerado dinamicamente via AJAX (endpoint `/voos/<id>/assentos/`) retornando JSON
5. Endpoint retorna lista de assentos com status (disponivel/ocupado)
6. Layout: grid com 3 assentos por fileira (ajustavel conforme capacidade do aviao)
7. JavaScript vanilla (sem dependencias adicionais)
8. Testes para o endpoint de assentos (min. 3 testes)

## Complexity Estimate

**Size:** L (Large)
**Points:** 8
**Justificativa:** Requer endpoint JSON, JavaScript frontend com DOM manipulation, CSS para grid de assentos, e integracao AJAX entre select de voo e grid.

## Risks

- **CSRF no AJAX:** Endpoint GET nao precisa de CSRF. Mitigacao: usar GET para leitura.
- **Voo sem selecao:** Grid nao deve aparecer se nenhum voo selecionado. Mitigacao: esconder grid ate que `change` event dispare no select.
- **Autenticacao no endpoint:** Endpoint deve exigir login. Mitigacao: `LoginRequiredMixin` ou `@login_required`.

## Dev Notes

### Endpoint JSON

```python
from django.http import JsonResponse
from django.contrib.auth.mixins import LoginRequiredMixin
from django.views import View

class VooAssentosView(LoginRequiredMixin, View):
    def get(self, request, pk):
        voo = Voo.objects.select_related('aviao').get(pk=pk)
        assentos_ocupados = list(
            voo.reservas.values_list('numero_assento', flat=True)
        )
        return JsonResponse({
            'max_passageiros': voo.aviao.max_passageiros,
            'assentos_ocupados': assentos_ocupados,
        })
```

### JavaScript (vanilla)

```javascript
document.getElementById('id_voo').addEventListener('change', function() {
    const vooId = this.value;
    const container = document.getElementById('seat-grid');
    if (!vooId) { container.innerHTML = ''; return; }

    fetch(`/voos/${vooId}/assentos/`)
        .then(r => r.json())
        .then(data => {
            container.innerHTML = '';
            for (let i = 1; i <= data.max_passageiros; i++) {
                const btn = document.createElement('button');
                btn.type = 'button';
                btn.textContent = i;
                btn.className = 'seat-btn';
                if (data.assentos_ocupados.includes(i)) {
                    btn.classList.add('occupied');
                    btn.disabled = true;
                } else {
                    btn.classList.add('available');
                    btn.addEventListener('click', () => {
                        document.getElementById('id_numero_assento').value = i;
                        document.querySelectorAll('.seat-btn.selected').forEach(b => b.classList.remove('selected'));
                        btn.classList.add('selected');
                    });
                }
                container.appendChild(btn);
            }
        });
});
```
