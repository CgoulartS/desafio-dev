## Story

**As a** avaliador senior,
**I want** ver uma arquitetura modular com separação de domínios, DRY, LGPD e cache,
**so that** o candidato demonstre maturidade técnica além do funcional.

## Acceptance Criteria

1. App `accounts/` criada com model `Cliente` (domínio de identidade)
2. App `flights/` criada com models `Aviao`, `Voo`, `Reserva` (domínio de negócio)
3. Módulo `core/` com `BaseModel` abstrata (UUID + created_at + updated_at)
4. Todos os 4 models herdam de `BaseModel` (zero repetição de id/timestamps)
5. `flights/` referencia `accounts/`, nunca o contrário (direção de dependência)
6. Views de Cliente restritas a staff (LGPD — dados pessoais protegidos)
7. Link "Clientes" na navbar visível apenas para staff
8. Cache no `DashboardService` com `cache.get_or_set()` (TTL 60s)
9. `CACHES` configurado em settings.py (LocMemCache dev, preparado para Redis)
10. App `voos/` removida completamente (substituída por accounts + flights)
11. README atualizado com nova estrutura e seção "Decisões Arquiteturais"
12. Todos os testes passando na nova estrutura
13. Migration limpa (1 migration por app)

## Complexity Estimate

**Size:** XL (Extra Large)
**Points:** 13
**Justificativa:** Reestruturação completa — mover models, views, forms, services, tests entre apps, refazer migrations, atualizar todas as referências, templates e URLs.

## Risks

- **Migrations quebradas:** Mover models entre apps requer drop + recreate. Mitigação: recriar banco limpo.
- **Imports circulares:** flights importando accounts. Mitigação: accounts nunca importa flights.
- **Templates referenciando paths antigos:** Mitigação: buscar e substituir todos os `voos/` por paths corretos.
- **Testes com imports antigos:** Mitigação: atualizar todos os imports nos test files.

### BaseModel

```python
import uuid
from django.db import models

class BaseModel(models.Model):
    id = models.UUIDField(primary_key=True, default=uuid.uuid4, editable=False)
    created_at = models.DateTimeField(auto_now_add=True)
    updated_at = models.DateTimeField(auto_now=True)

    class Meta:
        abstract = True
```
