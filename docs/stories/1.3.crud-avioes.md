## Story

**As a** usuario do sistema,
**I want** cadastrar, listar, editar e excluir avioes,
**so that** eu possa gerenciar a frota disponivel para voos.

## Acceptance Criteria

1. Model `Aviao` com campos: modelo (CharField), fabricante (CharField), max_passageiros (PositiveIntegerField)
2. ListView em `/avioes/` exibindo tabela com todos os avioes e acoes (editar, excluir)
3. CreateView em `/avioes/novo/` com formulario validado
4. UpdateView em `/avioes/<id>/editar/` com formulario pre-preenchido
5. DeleteView em `/avioes/<id>/excluir/` com pagina de confirmacao
6. Validacao: max_passageiros deve ser maior que 0
7. Mensagens flash de sucesso apos criar, editar e excluir
8. Todas as views protegidas por `LoginRequiredMixin`
9. Links de navegacao na navbar para lista de avioes
10. Testes unitarios para model e testes de integracao para views (min. 5 testes)

## Complexity Estimate

**Size:** M (Medium)
**Points:** 5
**Justificativa:** Primeiro CRUD completo — estabelece o padrao para as demais stories. Model, form, 4 views (CBV), 4 templates, URLs, admin, testes.

## Risks

- **Padrao de CRUD mal estabelecido:** Esta story define o padrao reutilizado nas Stories 2.1, 2.2 e 2.3. Se o padrao for inconsistente, propaga para todas. Mitigacao: Dev Notes com codigo de referencia detalhado.
- **SuccessMessageMixin no DeleteView:** Django nao suporta SuccessMessageMixin nativamente em DeleteView. Mitigacao: override do metodo delete() para adicionar mensagem flash manualmente.

## Dev Notes

### Padrao CBV com Mensagens Flash

```python
from django.contrib import messages
from django.contrib.messages.views import SuccessMessageMixin

class AviaoCreateView(LoginRequiredMixin, SuccessMessageMixin, CreateView):
    model = Aviao
    form_class = AviaoForm
    template_name = 'voos/aviao_form.html'
    success_url = reverse_lazy('aviao-list')
    success_message = 'Aviao cadastrado com sucesso!'
```

### Mensagens Flash no base.html

### URL Pattern (voos/urls.py)

```python
from django.urls import path
from . import views

urlpatterns = [
    path('', views.HomeView.as_view(), name='home'),
    path('avioes/', views.AviaoListView.as_view(), name='aviao-list'),
    path('avioes/novo/', views.AviaoCreateView.as_view(), name='aviao-create'),
    path('avioes/<int:pk>/editar/', views.AviaoUpdateView.as_view(), name='aviao-update'),
    path('avioes/<int:pk>/excluir/', views.AviaoDeleteView.as_view(), name='aviao-delete'),
]
```
