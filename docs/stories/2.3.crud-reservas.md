## Story

**As a** usuario do sistema,
**I want** criar, listar, editar e cancelar reservas associando clientes a voos com assentos unicos,
**so that** cada passageiro tenha um assento garantido sem conflitos.

## Acceptance Criteria

1. Model `Reserva` com campos: cliente (ForeignKey), voo (ForeignKey), numero_assento (PositiveIntegerField), criado_em (DateTimeField auto)
2. Constraint UNIQUE em (voo, numero_assento) — assento unico por voo
3. Constraint UNIQUE em (voo, cliente) — um cliente por voo
4. Validacao no form/model: numero_assento nao pode exceder max_passageiros do aviao do voo
5. Validacao no form/model: numero total de reservas do voo nao pode exceder max_passageiros
6. ListView em `/reservas/` exibindo tabela com cliente, voo, assento e acoes
7. CreateView em `/reservas/nova/` com selects de cliente e voo + campo de assento
8. UpdateView em `/reservas/<id>/editar/`
9. DeleteView em `/reservas/<id>/excluir/` com confirmacao
10. Mensagens de erro claras quando validacoes falham (assento ocupado, voo lotado)
11. Mensagens flash de sucesso para todas as operacoes
12. Todas as views protegidas por `LoginRequiredMixin`
13. Testes unitarios e de integracao cobrindo regras de negocio (min. 8 testes)

## Complexity Estimate

**Size:** L (Large)
**Points:** 8
**Justificativa:** Story mais complexa do projeto. 4 validacoes de negocio cruzadas (assento unico, cliente unico, capacidade maxima, assento valido), 2 UniqueConstraints, logica de edicao que deve excluir a propria instancia das queries. 13 ACs e min. 8 testes.

## Risks

- **Race condition em reservas simultaneas:** Dois usuarios podem reservar o mesmo assento ao mesmo tempo. Mitigacao: UniqueConstraint no banco garante integridade (IntegrityError como fallback).
- **Validacao de edicao incorreta:** Ao editar, queries devem excluir `self.instance.pk` para nao rejeitar a propria reserva. Mitigacao: Dev Notes com codigo detalhado cobrindo este caso.
- **Contagem de reservas inconsistente:** `voo.reservas.count()` pode incluir a reserva sendo editada. Mitigacao: subtrair 1 quando `self.instance.pk` existe.
- **Mensagens de erro genericas:** `forms.ValidationError` sem contexto confunde o usuario. Mitigacao: AC10 exige mensagens claras para cada cenario.

## Dev Notes

### Validacoes Criticas no Form

```python
class ReservaForm(forms.ModelForm):
    class Meta:
        model = Reserva
        fields = ['cliente', 'voo', 'numero_assento']

    def clean(self):
        cleaned_data = super().clean()
        voo = cleaned_data.get('voo')
        cliente = cleaned_data.get('cliente')
        numero_assento = cleaned_data.get('numero_assento')

        if voo and numero_assento:
            max_pass = voo.aviao.max_passageiros

            # Assento nao pode exceder capacidade
            if numero_assento > max_pass:
                raise forms.ValidationError(
                    f'Assento {numero_assento} invalido. O aviao comporta no maximo {max_pass} passageiros.'
                )

            # Verificar assento ocupado (excluir instancia atual em edicao)
            qs = Reserva.objects.filter(voo=voo, numero_assento=numero_assento)
            if self.instance.pk:
                qs = qs.exclude(pk=self.instance.pk)
            if qs.exists():
                raise forms.ValidationError(
                    f'Assento {numero_assento} ja esta ocupado neste voo.'
                )

        if voo:
            # Verificar capacidade do voo
            reservas_count = voo.reservas.count()
            if self.instance.pk:
                reservas_count -= 1  # Nao contar a propria reserva em edicao
            if reservas_count >= voo.aviao.max_passageiros:
                raise forms.ValidationError('Este voo ja esta com capacidade maxima.')

        if voo and cliente:
            # Verificar cliente duplicado no voo
            qs = Reserva.objects.filter(voo=voo, cliente=cliente)
            if self.instance.pk:
                qs = qs.exclude(pk=self.instance.pk)
            if qs.exists():
                raise forms.ValidationError('Este cliente ja possui reserva neste voo.')

        return cleaned_data
```
